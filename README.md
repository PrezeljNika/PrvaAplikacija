## Opis projekta
Projekt predstavlja mojo prvo mobilno aplikacijo, izdelano v Android Studiu z uporabo programskega jezika Java. Namen naloge je spoznati osnovno strukturo Android projekta, izdelavo uporabniškega vmesnika in uporabo osnovnih gradnikov.

## Uporabljene tehnologije
- Android Studio
- Java
- XML
- Android SDK

## Funkcionalnosti
- Prikaz in spreminjanje besedila Hello World!.
- Prilagajanje velikosti in sloga besedila.
- Dodajanje več gradnikov TextView.
- Uporaba gradnikov Button in CheckBox.
- Dodajanje Floating Action Button (FAB).
- Uporaba ConstraintLayout za razporejanje elementov.
- Shranjevanje besedil v datoteko strings.xml.
- Prikaz sporočil Toast in Snackbar.
- Prilagajanje videza in položaja Snackbar obvestila.


## Zagon aplikacije
1. Projekt odpremo v Android Studiu.
2. Izberemo emulator ali povežemo Android napravo.
3. Kliknemo gumb Run.
4. Aplikacija se zažene na izbrani napravi.
